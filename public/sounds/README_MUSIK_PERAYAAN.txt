MUSIK PERAYAAN DI ARENA

Berkas lagu Queen belum termasuk dalam paket source ini.

Pilihan 1: Buka Arena, aktifkan audio, lalu klik Pilih MP3 perayaan untuk memilih lagu pada komputer Arena.

Pilihan 2: Tempatkan MP3 lagu di folder ini dengan nama tepat:
we_are_the_champions.mp3

Lakukan build ulang untuk mode produksi dan mulai ulang aplikasi. Arena akan memakai berkas tersebut ketika host menekan Tentukan Juara.

Lihat PANDUAN_MUSIK_PERAYAAN.md pada folder utama proyek untuk petunjuk lengkap.
